# How to Install Terraform on Windows

# Downlaod terraform and Unpack and Install it
# Create a folder on C Drive Called "terraform" and Move the Installer there.
# Go to Windows start menu and type "env"
# Select "Edit the system Environment Variables"
# Click "Environment Variables"
# Under "System Variables" find a line starts with "Path"
# Click new and type "C:\Terraform"
# Click ok and close all windows.

# Open CMD or VS Code and type "terraform -v"
